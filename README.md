# CloudChain legal pages

Static Terms of Service, Privacy Policy, and account-deletion pages for CloudChain.

## Live URLs (GitHub Pages)

After Pages is enabled on `main` / `/ (root)`:

- Home: `https://omnisoft-official.github.io/cloudchain-legal/`
- Terms: `https://omnisoft-official.github.io/cloudchain-legal/terms.html`
- Privacy: `https://omnisoft-official.github.io/cloudchain-legal/privacy.html`
- Delete account: `https://omnisoft-official.github.io/cloudchain-legal/delete-account.html`

Use these links in Meta, Play Console, App Store Connect, and Firebase where a public policy URL is required.
